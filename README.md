# Vocal Coach (worship vocal trainer PWA)

Upload `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` to a folder in your GitHub Pages repo
(for example `Apps/vocal-coach/`). Open the page over https, then use "Add to Home screen".
Source is in `src/`; `python3 build.py` rebuilds `index.html`; `node test/core.test.js` runs the logic tests.
